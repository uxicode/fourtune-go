# 사주 엔진 입력 정책

- **연·월·일·시·분 범위:** `manseryeok@1.0.1`과 동일하게 **1900~2100** 연도 (README 기준). UI·API는 동일 범위로 검증합니다.
- **시 모름 (`timeUnknown: true`):** `unknownTimePolicy: "solar_noon"`(기본)일 때 **12:00(정오, 오시)** 를 사용합니다. `timeIsApproximate: true`로 표시하며, 실제 출생시와 다를 수 있음을 UI에서 안내합니다.
- **자시·자정:** 23~1시(자시), 0시(자시 경계) 등은 `manseryeok`의 시진 분리 규칙을 그대로 따릅니다. 엔진 동작이 바뀌지 않게 회귀 테스트로 고정합니다.
- **음력·윤달:** `isLunar: true`일 때 `isLeapMonth`를 반드시 전달합니다.
- **성별 (`gender`):** `대운` 순/역(陽男陰女順/陰男陽女逆 등)에만 사용하며, 그 외 용도에 쓰지 않습니다.
- **십성:** 일간(日干) 기준 천간 십성. 지지는 **지장 본기(本氣) 1자**만 쓰며, 본가·잠재·봉갑 등의 세 자 지장은 MVP에서 생략합니다.
- **신강/신약:** 월지(지지 오행)·년·월·시 천간의 십성(인·비겁·식상·재·관)에 가중치를 둔 **내부 휴리스틱**이며, 전문 명리 ‘신강/신약’ 판정을 대체하지 않습니다.
- **절기·大運 童限:** `SOLAR_TERM_BASE` 근사(출처: manseryeok MIT, yhj1024)를 사용, **3일=1년**으로 첫 대운 이전 연령을 내러냅니다. 節(12)만 사용(‘기’ 氣는 제외).
- **세운:** 양력 **연도**·간지는 `(year-4)%10, %12` 공식(중순·대표일 기준)으로, 연초(입춘 전후) 민감 구간은 별도 설명 권고.
- **격국(14 범주 참고):** 앱은 **자동으로 1개 격을 판정하지 않습니다.** 내려가는 격 설명은 **전부 참고용 나열**이며, 전통 명리의 격 판정·학파와 다를 수 있습니다.
